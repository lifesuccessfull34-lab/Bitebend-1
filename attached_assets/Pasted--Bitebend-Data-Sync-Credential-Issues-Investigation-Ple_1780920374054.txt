# Bitebend - Data Sync & Credential Issues Investigation

Please investigate and fix the following issues thoroughly. Do not apply temporary patches. Find the root cause and ensure proper database synchronization across Admin Panel and Restaurant Dashboard.

## 1. Registration Email & Password Mismatch

### Current Issue

When a restaurant registers, the email and password entered during signup are different from the credentials shown later in:

Restaurant Dashboard → Profile Section → Login Credentials

### Required Checks

1. Verify which database fields are storing:

   * Registration Email
   * Registration Password
   * Login Credential Email
   * Login Credential Password

2. Confirm whether multiple credential records are being created during registration.

3. Ensure the Restaurant Dashboard Login Credentials always display the actual email and password/account credentials used during registration.

4. Check the entire registration flow:

   * Frontend form
   * API request
   * Database insertion
   * Dashboard profile retrieval

5. Fix any mapping issues between auth tables and restaurant profile tables.
