Implement a new payment method for Bitebend using Personal UPI + UPI Deep Link flow while keeping the existing Razorpay Payment Gateway completely unchanged.

This new flow should become the default lightweight payment option for restaurants that do not activate Razorpay.

==================================================
RESTAURANT DASHBOARD
====================

Location:

Profile → Payment & Communication

Add:

UPI ID field:
Example:

restaurant@okaxis

Merchant/Restaurant Name:
Example:

ABC Restaurant

Enable Personal UPI toggle:
ON / OFF

Keep existing Razorpay settings exactly as-is.

Logic:

IF Razorpay activated:
→ Existing Razorpay flow continues

ELSE IF Personal UPI enabled:
→ Use Personal UPI payment flow

==================================================
CUSTOMER PAYMENT FLOW
=====================

Customer:

Scan menu QR
→ Add items
→ Checkout
→ Pay Now

On mobile:

Click:

Pay via UPI

Generate dynamic UPI deep link:

upi://pay?
pa=<upiId>
pn=<restaurantName>
am=<orderAmount>
cu=INR
tn=Order-<orderId>

Example:

upi://pay?pa=restaurant@okaxis&pn=ABC Restaurant&am=250
