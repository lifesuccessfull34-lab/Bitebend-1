Replace the existing Bitebend checkout + payment architecture completely and migrate to a new platform-payment system using Razorpay Route / Split Settlement architecture.

NEW PAYMENT FLOW:

PHASE 1 — SUPER ADMIN AS PAYMENT OWNER

1. Super Admin owns the master Razorpay account.
2. Restaurants are onboarded under the Super Admin account as linked/sub-accounts.
3. Every restaurant profile must store:

   * restaurantId
   * linkedAccountId (Razorpay Route account)
   * settlement configuration
   * restaurant revenue %
   * Bitebend commission %
   * payout status

Database example:

Restaurant:

* id
* name
* razorpayLinkedAccountId
* commissionPercent
* restaurantPercent
* settlementStatus

Example:
Order Amount = ₹1000

Restaurant receives:
₹950

Bitebend receives:
₹50

Revenue split must happen automatically through Razorpay Route split transfers.

No manual commission calculation later.

---

PHASE 2 — CUSTOMER CHECKOUT FLOW

Remove current checkout/payment architecture entirely:

REMOVE:

* payment screenshot upload
* OCR verification
* payment proof processing
* manual QR upload logic
* old bill payment flow
* pending screenshot verification logic

Replace with:

Customer Flow:

Menu → Cart → Checkout → Razorpay Payment Gateway

At checkout:

1. Customer clicks "Pay Now"
2. Open Razorpay Standard Checkout
3. Payment methods:

* UPI
* GPay
* PhonePe
* Paytm
* Cards
* Net Banking
* Wallets

Customer pays through any supported app.

After payment success:

Razorpay webhook automatically confirms payment.

No screenshot upload required.

---

PHASE 3 — WEBHOOK BASED ORDER CONFIRMATION

Create secure Razorpay webhook endpoint:

POST /api/payments/webhook

Handle:

payment.captured
payment.authorized
order.paid

Webhook flow:

If payment successful:

1. Mark order = PAID

2. Save:

   * paymentId
   * razorpayOrderId
   * amount
   * status
   * restaurantId
   * timestamp

3. Notify restaurant instantly

4. Trigger order confirmation

If payment fails:

order remains pending

Restaurant can accept CASH payment manually.
