==================================================
REQUIRED PARAMETERS
===================

Use:

pa = UPI ID
pn = Merchant/restaurant name
am = Amount
cu = INR
tn = Transaction note
tr = Unique order reference

Example:

upi://pay?pa=restaurant@okaxis&pn=ABC Restaurant&am=250&cu=INR&tr=ORDER123&tn=Order-123

==================================================
IMPORTANT
=========

URL encode values:

encodeURIComponent()

Example:

pn=${encodeURIComponent(name)}

tn=${encodeURIComponent(note)}

Reason:

Restaurant names with spaces break UPI parsing.

Bad:

ABC Restaurant

Good:

ABC%20Restaurant
