Add endpoint:

POST /api/create-order

Behavior:

* Accept amount in paise
* Validate amount >=100
* Create Razorpay order
* currency: INR
* Generate receipt id
* Return:
  {
  order_id,
  amount,
  currency
  }

Error handling:

* Razorpay auth failure -> 401
* API errors -> 500

Add endpoint:

POST /api/verify-payment

Input:
{
razorpay_order_id,
razorpay_payment_id,
razorpay_signature
}

Verification:
Generate HMAC-SHA256:
order_id + "|" + payment_id

Use RAZORPAY_KEY_SECRET.

Return success only if signatures match.

If mismatch:
return 400
Do NOT mark order paid.
